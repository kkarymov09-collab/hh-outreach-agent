## Instagram пайплайн — как запускать

### Предварительно: получить куки
1. Зайди в instagram.com в браузере
2. DevTools → Network → любой запрос → Headers → `Cookie:`
3. Скопируй всю строку и сохрани в `.ig_cookie`

### Шаги:

```bash
# Шаг 1 — найти аккаунты по хэштегам
node ig_scanner.js
# → ig_accounts.json

# Шаг 2 — обогатить профили и поставить скоры
node ig_enricher.js
# → ig_enriched.json, ig_enriched.csv

# Шаг 3 — сгенерировать персонализированные DM
node ig_outreach.js
# или с превью без сохранения:
node ig_outreach.js --dry-run
# → ig_contacts.json, ig_contacts.csv

# Шаг 4 — отправить DM (нужен pip install instagrapi)
IG_USER=твой_логин IG_PASS=твой_пароль python ig_sender.py --limit 20
# dry-run без отправки:
IG_USER=x IG_PASS=x python ig_sender.py --dry-run

# Шаг 5 — follow-up тем, кто не ответил через 2+ дня
IG_USER=твой_логин IG_PASS=твой_пароль python ig_followup.py
```

### Лимиты безопасности (встроены в код):
- `ig_sender.py`: задержка 45–90с между DM, дневной лимит 25
- `ig_followup.py`: задержка 60–120с, дневной лимит 20
- `ig_enricher.js`: CONCURRENCY=3, задержка 1200мс между батчами

## Instagram скоринг (ig_enricher.js)

| Условие | Баллы |
|---|---|
| Нет сайта | +3 |
| Категория еда / кофе / ресторан | +2 |
| 100–10 000 подписчиков | +2 |
| 10 000–50 000 подписчиков | +1 |
| Короткое или пустое bio | +1 |
| 20–300 постов | +1 |

Минимальный score для включения в результат: **3**.
Максимальное число подписчиков: **100 000**.

## Приоритетные ниши для питча

1. **Косметология / клиники** — #1 по скорости конверсии. Высокий LTV клиента, нет сайта у 70%+ малых студий, боль с онлайн-записью понятна всем. **Сейчас основная ниша.**
2. **Кофейни / кафе** — легко найти через хэштеги, быстрый цикл сделки, хорошо видно «плохой дизайн»
3. **Рестораны / бары** — крупнее, дольше принимают решение, но чек выше
4. **Пиццерии / суши / доставка** — ищут онлайн-заказ, хорошо откликаются

**Убрали из быстрой воронки:** B2B, корпоративы — длинный цикл сделки.

## Портфолио (portfolio/index.html)

### Технические детали:
- Чистый HTML/CSS/JS, без фреймворков
- Шрифты: Unbounded (800/600) + Onest — Google Fonts
- Тёмная тема: `--bg: #08080a`, акцент `--accent: #c8ff3e` (лайм)
- Spotlight-эффект: radial gradient следит за мышью (z-index: 0)
- Noise-текстура: SVG filter на `body::before`
- Scroll-reveal: IntersectionObserver + setTimeout(300ms) fallback
- Count-up анимация для стат в герое
- Card tilt эффект на сервис-карточках
- Marquee на CSS animation
- Адаптивное бургер-меню

### Секции:
1. **Nav** — фиксированный, blur, `scrolled` класс при скролле
2. **Hero** — заголовок «Сайт + AI-бот для клиники за 5 дней. Не нравится — не платишь.»
3. **Marquee** — бегущая строка услуг
4. **Services** — 4 карточки: лендинг / AI-бот / связка / автоматизация
5. **Work** — сетка кейсов (flagship: Astana Business Cup)
6. **Process** — 4 шага: бриф → концепт за 24ч → правки → запуск
7. **Why** — «Видите результат до оплаты. Риск — мой.»
8. **Pricing** — 3 тира: Лендинг (250к) / Лендинг+бот popular (380к) / AI-бот (150к)
9. **CTA** — WhatsApp + Telegram
10. **Footer**
